# Security Policy

## Supported version

The latest release of Xamppify is supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Report it privately to the repository owner with:

- a clear description of the issue;
- affected version and Windows/XAMPP version;
- reproducible steps or a minimal proof of concept;
- possible impact; and
- any suggested mitigation.

Examples include filesystem-boundary bypasses, arbitrary command execution, credential exposure, unsafe database behavior, and certificate-handling flaws. The maintainer will acknowledge the report and coordinate a fix before disclosure.
